# Demo photographs (GLD-079)

The photographs the demo generator files as documents of the hero cases (docs/DEMO_SCRIPT.md
§4). **None is a real photograph**: each was generated by an AI image tool from the prompt
below, then reduced for the repository (1280 × 956, JPEG quality 78, metadata stripped:
`convert <in> -auto-orient -resize '1280x960>' -strip -sampling-factor 4:2:0 -interlace JPEG
-quality 78 <out>.jpg`). They show no recognizable person, no readable licence plate and no real
brand; places and buildings are invented. Photographs carry no language, so every demo language
uses the same files; the PDF documents are generated by the code in the demo language.

Provenance: generated on 2026-11-26 by the product owner with Google Gemini (web app; image
model reported as « hydrogen », presumably the one nicknamed Nano Banana). Keep each file under 400 KB (`TestAssets`) and record any new image here, with its
prompt.

Every prompt ends with the common rules: *realistic smartphone photo, landscape 4:3, French-speaking
Swiss residential architecture, no recognizable person, no readable licence plate, no real logo or
brand name, no readable text except the one asked for.*
